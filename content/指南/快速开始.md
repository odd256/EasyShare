## 配置站点

编辑 `config/site.ts`，修改标题、作者和完整站点地址。社交链接留空会隐藏，统计默认关闭。

## 本地预览

安装 Node.js 22.6 或更高版本，推荐 Node.js 22，然后在项目目录运行：

```bash
npm ci
npm run dev
```

默认访问 http://localhost:3000。如果站点地址包含仓库路径，例如 `/my-blog`，本地地址也要加上这个路径。

## 写第一篇文章

在 `content/` 下创建 Markdown 文件，填写标题、日期、标签和摘要。参考 [Markdown 示例](<Markdown 示例.md>)，再阅读 [[学习笔记/第一篇 笔记|第一篇笔记]]。

## 发布

先修改站点地址，运行 `npm run check` 和 `npm run preview`。在 GitHub 仓库设置中将 Pages 来源设为 GitHub Actions，推送到 main 后自动构建部署。详细步骤见项目 README。
