## 浏览器覆盖

- 首页标题、作者、中文语言标记；未加载默认统计脚本。
- 搜索文章后跳转到中文与空格文件名对应的页面，并刷新直接访问。
- 主题切换及刷新后的主题保持。
- 本地图片加载、放大与 Escape 关闭。
- 跨目录 Markdown 链接、笔记链接别名、中文标题锚点；外部网站和邮箱链接保持原地址。
- 公式和代码渲染、归档搜索、无结果状态、标签参数筛选。
- 移动端首页与文章导航，检查页面无横向溢出；截图检查桌面和移动端布局。
- 仅保留首页时，首页笔记列表、搜索与归档均可显示空状态。测试后已恢复全部示例文章。

## 验证中修复的问题

- Markdown 原生链接与图片增加基础路径处理，相对文章链接按源文件目录解析。
- 标题与目录使用一致的中文锚点规则，支持手写 `#代码` 跳转。
- 本地静态预览的中文目录跳转使用合法的 URL 编码。
- 补齐 Windows 静态导出中的导航缓存文件名，避免预取与导航请求 404。
- 没有文章时生成仅返回 404 的动态路由占位，满足静态导出要求，不计入文章列表。
